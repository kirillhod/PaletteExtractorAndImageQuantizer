Help

Load an image, extract a palette or choose a fixed one, compare the result, and export a validated indexed PNG, palette strip, palette file, or reduced PNG. Edit colors, locks, and order as needed; undo and redo work while editing.

v1.2 adds a palette editor with locks and undo, CIEDE2000 quality, shareable URL settings, and a saved local session.

How it works

  1. Build a 5-bit, alpha-weighted color histogram.
  2. Extract a palette or load a fixed one; edit colors, locks, and order.
  3. Map pixels exactly up to 65,536 distinct colors, otherwise with a 6-bit LUT.
  4. Dither optionally, then encode, decode, and compare before offering the file.

Palette order and the preview

The preview and Reduced PNG use the available colors. Moving a swatch changes export order and indices, not the color set, so the image looks the same unless two colors tie exactly; ties go to the lowest index. Adding, removing, or editing a color changes the mapping. An indexed PNG keeps the same visible colors after a move (apart from ties), but its PLTE order and index map change; the transparent index follows its color, not the slot.

Quality

The Quality section compares the preview with the source using CIEDE2000. Mean, p95, and max summarize the error; the map runs from dark blue at 0 to red at 20+, and the worst-pixel list gives coordinates. Fully transparent pixels are skipped; contrast checks are not included.

Shareable settings

The URL hash stores settings only: mode, extractor, colors, working space, built-in palette, dither, alpha, sort, and transparent index. It never includes the image, palette edits, locks, or quality results.

Saved session

The last image, settings, palette entries, locks, order, selection, edit mode, and undo/redo history stay in this browser's IndexedDB. A URL with different settings overrides the saved settings and re-extracts the palette. Use Forget saved session to remove it.
