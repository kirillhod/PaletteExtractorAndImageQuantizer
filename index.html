Help

Load an image, extract a palette or choose a fixed one, compare the result, and export an indexed PNG, palette strip, palette file, or reduced PNG. Every result is checked before download and can also be copied to the clipboard. Edit colors, locks, and order as needed; undo and redo work while editing.

includes the palette editor with locks and undo, perceptual ordering, picked-color anchors, quality metrics, shareable URL settings, and a saved local session.

How it works

  1. Build a 5-bit, alpha-weighted color histogram.
  2. Extract a palette or load a fixed one; edit colors, locks, and order.
  3. Map pixels exactly up to 65,536 distinct colors, otherwise with a 6-bit LUT.
  4. Dither optionally, then encode, decode, and compare the result before offering the file.

Palette order and the preview

Export order changes, the color set does not. A move rewrites export indices and the HEX list. The preview and Reduced PNG keep the same look unless two colors tie exactly; ties go to the lowest index. Adding, removing, or editing a color changes the mapping. An indexed PNG keeps the same visible colors after a move (apart from ties), but its PLTE order and index map change; the transparent index follows its color, not the slot. Click empty space in the palette strip or press Esc while the palette has focus to clear the selection; with no selection, Pick fills the HEX field for Add.

Perceptual orders compare colors with Delta E (CIEDE2000). Only the order and export indices change.

Smooth
keeps the light-to-dark flow and removes local jumps.
Color path
follows the closest colors from the darkest to the lightest.
Flow
keeps neighboring colors as close as possible without pinning the ends.

Picked colors keep a marker on the image while Edit is on. Drag a marker to recolor its swatch, or focus it and use arrow keys; Esc cancels a drag. Extracted and imported colors have no marker until you pick them. Markers are saved with the session and never enter exports.

Quality

Lower ΔE00 means a closer preview. Mean, p95, and max summarize the CIEDE2000 error between the preview and the source; the map runs from dark blue at 0 to red at 20+, and the worst-pixel list gives coordinates. Fully transparent pixels are skipped; contrast is not checked.

Shareable settings

The URL hash stores settings only. It covers mode, extractor, colors, working space, built-in palette, dither method, strength, serpentine, edge stop, alpha threshold, sort, and transparent index. The image, palette edits, locks, and quality results never enter it.

Saved session

The last session stays in this browser. It keeps the image, settings, palette entries, locks, order, selection, markers, edit mode, and undo/redo history in IndexedDB. A URL with different settings overrides the saved settings and re-extracts the palette. Use Forget saved session to remove the stored copy.
